# Machine Learning with PyTorch and Scikit-Learn


## About the Book

This book teaches machine learning (ML) and deep learning step by step using Python. It starts from the very basics and slowly moves to advanced topics like Transformers, GANs and Graph Neural Networks. Many algorithms are first written **from scratch** so you understand how they work. After that, the book shows how to use ready-made libraries like **scikit-learn** and **PyTorch**.

The book has **19 chapters** and can be seen in two parts:

- **Part 1 (Chapters 1–11): Classic Machine Learning** with NumPy and scikit-learn
- **Part 2 (Chapters 12–19): Deep Learning** with PyTorch

## Chapter-wise Summary

| # | Chapter | What you learn (in short) |
|---|---------|---------------------------|
| 1 | Giving Computers the Ability to Learn from Data | What ML is, its 3 types (supervised, unsupervised, reinforcement), basic terms and setting up Python. |
| 2 | Training Simple ML Algorithms for Classification | Build a Perceptron and Adaline from scratch, learn gradient descent and feature scaling. |
| 3 | A Tour of ML Classifiers Using Scikit-Learn | Logistic regression, SVM, kernel SVM, decision trees and KNN using scikit-learn. |
| 4 | Building Good Training Datasets | Handle missing data and categorical data, split data, scale features and select important features. |
| 5 | Compressing Data via Dimensionality Reduction | Reduce the number of features using PCA, LDA and t-SNE. |
| 6 | Model Evaluation and Hyperparameter Tuning | Pipelines, k-fold cross-validation, learning curves, grid search and metrics like precision, recall and ROC. |
| 7 | Ensemble Learning | Combine many models using majority voting, bagging, AdaBoost and gradient boosting (XGBoost). |
| 8 | Sentiment Analysis | Classify IMDb movie reviews as positive/negative using bag-of-words, TF-IDF and topic modelling (LDA). |
| 9 | Regression Analysis | Predict numbers (like house prices) using linear, robust (RANSAC), regularized and polynomial regression. |
| 10 | Clustering Analysis | Group unlabeled data using k-means, hierarchical clustering and DBSCAN. |
| 11 | Neural Network from Scratch | Build a multilayer neural network with NumPy and learn backpropagation on handwritten digits (MNIST). |
| 12 | Neural Network Training with PyTorch | PyTorch basics: tensors, data loaders, building models and activation functions. |
| 13 | Going Deeper – The Mechanics of PyTorch | Computation graphs, autograd, `torch.nn` and PyTorch Lightning, with two small projects. |
| 14 | Convolutional Neural Networks (CNNs) | Image classification using CNNs, including smile detection from face images. |
| 15 | Recurrent Neural Networks (RNNs) | Work with sequence data like text using RNNs and LSTMs. |
| 16 | Transformers and Attention | Self-attention, the Transformer model, GPT/BERT ideas and fine-tuning BERT. |
| 17 | Generative Adversarial Networks (GANs) | Generate new images using GANs, DCGAN and Wasserstein GAN. |
| 18 | Graph Neural Networks (GNNs) | Learn from graph data (like molecules) using GNNs and PyTorch Geometric. |
| 19 | Reinforcement Learning | Teach an agent to take decisions using rewards: Q-learning and deep Q-learning. |

## Tools and Libraries Used

- **Python 3**
- **NumPy**, **pandas**, **Matplotlib** — data handling and plotting
- **scikit-learn** — classic ML algorithms
- **PyTorch**, **PyTorch Lightning**, **PyTorch Geometric** — deep learning
- **Hugging Face Transformers** — for BERT
